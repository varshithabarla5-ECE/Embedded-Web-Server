## Project Name
Embedded Web Server

## Project Scope
The Embedded Web Server project uses an ESP32 microcontroller to create a web server that can be accessed through a web browser over a Wi-Fi network. The server hosts a webpage that allows users to remotely control an LED using a web browser.

## Project Description
This project demonstrates the implementation of a web server using the ESP32 microcontroller. The ESP32 connects to a Wi-Fi network and hosts a webpage that provides ON and OFF controls for an LED. The project highlights the use of embedded sytems and IoT technology for remote device control.
